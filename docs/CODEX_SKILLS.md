## New machine quick setup

If you continue this repo on another Mac or workstation, copy the repo skill into the local Codex skills directory:

```bash
mkdir -p "${CODEX_HOME:-$HOME/.codex}/skills/heimdall-app-type-extension"
cp "/path/to/repo/skills/heimdall-app-type-extension/SKILL.md" \
  "${CODEX_HOME:-$HOME/.codex}/skills/heimdall-app-type-extension/SKILL.md"
```

In this project the repo copy is the canonical one. If the local copy drifts, overwrite it from the repo version.
